# Canonical Source Artwork

This directory contains original, immutable source artwork and storyboards.

## Structure
- `characters/death/`: Source walk sheet and detailed character illustrations for Death.
- `characters/love/`: Source walk sheet and detailed character illustrations for Love.
- `characters/fear/`: Detailed character sheets for Fear.
- `characters/general/`: Detailed character sheet for The General.
- `storyboards/`: Full storyboard plates for Acts I through IV.

## Rules
- **DO NOT MODIFY**: These files are immutable source reference assets.
- **DO NOT SERVE**: These files must not be copied into client production bundles directly.
